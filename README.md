## Cleaning policy

PM2.5 is the primary measure: missing/non-numeric, negative or above-999 readings are dropped and logged. Negative or above-999 PM10/NO2 values are set to NULL and then imputed with that station's valid median. Missing temperature is forward-filled within a station; a leading gap uses that station's median. Fahrenheit readings for the two flagged stations are converted to Celsius. Duplicate station/date/hour keys keep the first observation. Per-station min-max and z-score normalisations are stored alongside the raw PM2.5 measurement.

## Complexity notes

- CSV scan and validation: O(n) time for n input rows.
- Min-max and z-score after grouping by station: O(n) time.
- SQLite station/date indexed lookup: approximately O(log n + k), where k is the number of matching readings.
- Python loop and pandas/SQL grouped means: all perform O(n) work on n rows, with different constant factors and memory/storage trade-offs.
- Lexicon sentiment: O(w) for w complaint tokens; extractive sentence ranking additionally sorts the sentence scores.
